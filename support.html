Chiply Support

What Chiply does

Chiply helps you run a poker home game. Add players and a chip set. Record each player's buy-ins. At the end of the game, enter final chip counts. Chiply calculates who pays whom. All game data stays on your device.

FAQ

How do I add an OpenAI API key?

  1. Get an API key from your OpenAI account at platform.openai.com.
  2. Open Chiply and go to Settings.
  3. Paste your key into the OpenAI API key field.

Chiply stores this key in the iOS Keychain on your device. You only need to do this once, and only if you want to use the AI count feature.

What does the AI count cost? Whose account does it use?

The AI count feature uses your own OpenAI account, not ours. OpenAI bills API usage to the account that owns the API key. Check current pricing on the OpenAI pricing page. Chiply itself does not charge you for the AI count.

How do I count chips without AI?

You do not need an OpenAI API key to use Chiply. You can enter chip counts by hand on the count screen for each player, without taking a photo or using the AI count button.

How do I delete a game or all data?

  • To delete one game, swipe left on the game in the game list and tap Delete.
  • To delete everything, go to Settings and use "Reset all data".
  • To remove all Chiply data from your device, delete the app.

How do I export my game history?

Go to a game's history or settings screen and choose Export. Chiply can export as JSON, CSV, or a ZIP file. Chiply opens the iOS share sheet so you can save the file or send it wherever you choose.
